# Milestone 4：销量回顾 Agent — 闭环归因与策略进化

## 目标

**总结过去**，并把教训**自动喂给选品 Agent**。

## 核心 Issues

| Issue | 标题 | 说明 |
|-------|------|------|
| 4.1 | 多维度销售复盘看板 | 自动生成周报/月报，分析各渠道（直播、私域、货架）的贡献度 |
| 4.2 | 退货率深度归因 | 分析评价中的语义信息（如「色差大」「偏小」），反馈给选品和质检环节 |
| 4.3 | 策略迭代反馈环 | 将本季度的「避雷点」（如某面料易皱导致高退货）存入 Agent 的长期记忆（Memory），在下一轮选品时自动拦截类似款式 |

## 验收标准（建议）

- 周报/月报可自动生成（含渠道贡献、同比环比、重点 SKU），支持导出或推送。
- 退货原因有结构化/标签化归纳，并能关联到具体款式或属性。
- 选品流程中能读取「避雷点」记忆，并在建议中体现拦截或提醒。

## 优先级与周期

- **P0（必做）**，与内部数据集成一起在 Week 1–2 落地，形成「先看清生意再优化」的闭环。
