# Milestone 2：选品 Agent — 从「直觉」到「预测」

## 目标

基于市场趋势和历史表现，推荐下一季的**爆款**或**补位款**。

## 核心 Issues

| Issue | 标题 | 说明 |
|-------|------|------|
| 2.1 | 流行趋势映射逻辑 | 编写 Prompt 令 Agent 将社媒热点转化为具体的商品需求（例如：社媒「美拉德」热度上升 → 建议增加棕色系裙装选品） |
| 2.2 | 竞品差异化分析（Gap Analysis） | Agent 自动对比竞品上新速度与价格区间，识别己方产品线的缺位 |
| 2.3 | 首单定量策略建议 | 根据选品的「风险等级」自动给出首批下单量（MOQ）建议，防止首单盲目铺货 |

## 验收标准（建议）

- 输入当季趋势关键词或标签，Agent 能输出具体品类/款式/色系选品建议。
- 能输出竞品对比视图（上新节奏、价格带），并标出己方缺口。
- 对每条选品建议给出首单量区间及风险等级说明。

## 优先级与周期

- 属 **P2（进阶）**，建议在 Week 5–8 与趋势抓取、标签体系配合推进。
