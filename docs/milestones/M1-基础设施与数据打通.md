# Milestone 1：基础设施与数据「血液」打通

## 目标

让 Agent 能够**「看见」**公司库存实时状态，并**「听见」**市场流行趋势。

## 核心 Issues

| Issue | 标题 | 说明 |
|-------|------|------|
| 1.1 | 内部 ERP/OMS 接口集成 | 开发标准 API 插件，让 Agent 能实时查询 SKU 销量、在途库存、退货率 |
| 1.2 | 外部趋势抓取工具（Scraper） | 集成 TikTok/小红书/Instagram 的热门标签爬取插件，获取当季流行元素（如「多巴胺穿搭」「静奢风」） |
| 1.3 | 商品多维标签化（Tagging） | 利用多模态大模型（如 Gemini 1.5 Pro）自动给图库中的商品打标签（领型、材质、风格、颜色），建立结构化索引 |

## 验收标准（建议）

- Agent 能通过统一接口拉取 ERP/OMS 的 SKU 级销量、在途、退货数据。
- 至少一个社媒渠道的热门标签/趋势可被定时抓取并结构化存储。
- 商品图库具备可查询的多维标签索引（领型、材质、风格、颜色等）。

## 优先级与周期

- 内部数据集成（Issue 1.1）为 **P0**，建议 Week 1–2 与销量回顾一起落地。
- 1.2、1.3 可作为 P1/P2 在后续迭代中完成。
