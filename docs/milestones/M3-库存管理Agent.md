# Milestone 3：库存管理 Agent — 效率与流转

## 目标

**自动预警断货风险**，**智能处理呆滞库存**。

## 核心 Issues

| Issue | 标题 | 说明 |
|-------|------|------|
| 3.1 | 动态库存预警系统（Alerting） | 设定逻辑：当「剩余库存 / 日均销量 < 补货周期」时，Agent 自动推送到业务员企业微信 |
| 3.2 | 滞销品清理决策树 | Agent 定期扫描库存：库龄 > 60 天且转化率 < 1% 的商品，自动给出「满减」「直播间秒杀」或「跨仓调拨」方案 |
| 3.3 | 智能补货计算器 | 集成 Code Interpreter 工具，计算最优订货量（EOQ），考虑季节性衰减系数 |

## 验收标准（建议）

- 满足断货条件时，企业微信/钉钉等渠道能收到可操作的预警（含 SKU、建议补货量或链接）。
- 滞销品列表及对应清理策略（满减/秒杀/调拨）可自动生成并导出。
- 补货计算器能输入周期、成本、销量等，输出建议订货量（含 EOQ 与季节性系数说明）。

## 优先级与周期

- **P1（提效）**，建议 Week 3–4 在内部数据打通后落地。
