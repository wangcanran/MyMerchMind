# Issue 4.2：退货率深度归因

**Milestone:** M4 - 销量回顾 Agent  
**优先级:** P0 / P1

## 描述

分析评价中的**语义信息**（如「色差大」「偏小」），将退货原因**结构化**，并**反馈给选品和质检环节**。

## 验收标准

- [ ] 从评价/退货备注中抽取原因标签（色差、尺码、质量等）
- [ ] 可按 SKU/品类/时段汇总退货原因分布
- [ ] 结论可被选品 Agent 或质检流程引用（如「某款色差投诉多」→ 选品时慎选同色系/同厂）

## 依赖与备注

- 依赖 1.1 中的退货数据及评价文本；可结合 NLP/大模型做语义聚类或打标。
