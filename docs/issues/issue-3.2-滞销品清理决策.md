# Issue 3.2：滞销品清理决策树

**Milestone:** M3 - 库存管理 Agent  
**优先级:** P1

## 描述

Agent **定期扫描**库存，对满足条件的商品自动给出清理方案：

- **条件示例：** 库龄 > 60 天 且 转化率 < 1%
- **方案示例：** 「满减」「直播间秒杀」「跨仓调拨」等

## 验收标准

- [ ] 滞销品列表可自动生成（库龄、转化率、库存金额等字段）
- [ ] 每条 SKU 有推荐策略（满减/秒杀/调拨/其他）及简要理由
- [ ] 输出可导出为 Excel 或推送至业务侧，便于执行

## 依赖与备注

- 依赖 Issue 1.1（库存与销量/转化数据）。策略树可配置（阈值、规则优先级）。
