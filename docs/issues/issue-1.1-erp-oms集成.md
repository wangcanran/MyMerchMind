# Issue 1.1：内部 ERP/OMS 接口集成

**Milestone:** M1 - 基础设施与数据打通  
**优先级:** P0

## 描述

开发标准 API 插件，让 Agent 能**实时查询**：

- SKU 销量
- 在途库存
- 退货率

## 验收标准

- [ ] 提供统一 API（或适配层），对接公司现有 ERP/OMS
- [ ] Agent 可通过 Tool 调用查询：按 SKU/时间范围的销量、在途、退货率
- [ ] 接口具备鉴权与限流，适合生产环境

## 依赖与备注

- 若 ERP 标签不统一（如颜色「咖啡」「深棕」混用），需配合**标签归一化**预处理（见避坑指南）。
