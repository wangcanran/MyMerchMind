# Issue 1.3：商品多维标签化（Tagging）

**Milestone:** M1 - 基础设施与数据打通  
**优先级:** P2

## 描述

利用**多模态大模型**（如 Gemini 1.5 Pro）对图库中的商品自动打标签，建立结构化索引，例如：

- 领型
- 材质
- 风格
- 颜色

便于选品与复盘时按维度筛选、归因。

## 验收标准

- [ ] 商品主图可批量/增量送入多模态模型，输出结构化标签
- [ ] 标签写入统一索引（DB 或搜索引擎），支持按领型/材质/风格/颜色查询
- [ ] 与公司已有颜色/材质等主数据做**归一化**映射，避免同义不同名

## 依赖与备注

- 依赖 M1 数据规范；标签体系需与选品 Agent、销量回顾归因共用同一套维度。
