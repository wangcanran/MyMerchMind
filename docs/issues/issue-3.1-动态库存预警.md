# Issue 3.1：动态库存预警系统（Alerting）

**Milestone:** M3 - 库存管理 Agent  
**优先级:** P1

## 描述

设定逻辑：

- 当 **剩余库存 / 日均销量 < 补货周期** 时  
- Agent **自动推送**预警到业务员**企业微信**（或钉钉/飞书等）

避免断货后才被发现。

## 验收标准

- [ ] 支持按 SKU 或品类配置「补货周期」与预警阈值
- [ ] 满足条件时自动触发推送，内容包含：SKU、当前库存、日均销量、建议补货量或链接
- [ ] 可配置接收人/群，且避免重复轰炸（如同一 SKU 24 小时内仅提醒一次）

## 依赖与备注

- 依赖 Issue 1.1（ERP/OMS 实时销量与库存）。日均销量建议用近期滚动窗口计算。
