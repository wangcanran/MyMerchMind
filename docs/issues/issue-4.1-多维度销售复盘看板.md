# Issue 4.1：多维度销售复盘看板

**Milestone:** M4 - 销量回顾 Agent  
**优先级:** P0

## 描述

**自动生成**周报/月报，分析各渠道贡献度，例如：

- 直播
- 私域
- 货架

替代人工整理周报，让管理层「看清生意现状」。

## 验收标准

- [ ] 支持按周/月自动生成报告，包含：各渠道销量、占比、同比/环比
- [ ] 可配置重点 SKU 或品类，在报告中突出展示
- [ ] 报告可导出（如 PDF/Excel）或推送至企业微信/邮件；若用 Python Interpreter 生成，需有明确流程文档（见用户需求：可后续写「如何利用 Python Interpreter 自动生成周报」的具体逻辑）

## 依赖与备注

- 依赖 Issue 1.1（ERP/OMS 按渠道的销售数据）。与 4.2、4.3 共同构成「销量回顾」闭环。
