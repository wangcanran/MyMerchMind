# Issue 2.2：竞品差异化分析（Gap Analysis）

**Milestone:** M2 - 选品 Agent  
**优先级:** P2

## 描述

Agent **自动对比**竞品与己方：

- 上新速度
- 价格区间

识别己方产品线的**缺位**，为补位选品提供依据。

## 验收标准

- [ ] 支持配置竞品列表及数据来源（爬虫/手工录入/第三方数据）
- [ ] 输出对比视图：品类/价格带/上新节奏，并标出己方空白或弱势区间
- [ ] 结论可被选品 Agent 引用，用于生成「补位款」建议

## 依赖与备注

- 竞品数据需可持续更新；若仅手工维护，需明确更新频率与责任人。
