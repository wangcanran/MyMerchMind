# Issue 1.2：外部趋势抓取工具（Scraper）

**Milestone:** M1 - 基础设施与数据打通  
**优先级:** P2

## 描述

集成 **TikTok / 小红书 / Instagram** 的热门标签爬取插件，获取当季流行元素，例如：

- 「多巴胺穿搭」
- 「静奢风」

供选品 Agent 做趋势映射（见 Issue 2.1）。

## 验收标准

- [ ] 至少一个平台（建议先小红书或抖音）的热门标签/话题可定时抓取
- [ ] 数据以结构化形式存储（时间、标签名、热度/参与度等）
- [ ] Agent 可通过 Tool 查询近期趋势列表

## 依赖与备注

- 需遵守各平台 robots.txt 与使用条款，必要时采用官方 API 或合作数据源。
