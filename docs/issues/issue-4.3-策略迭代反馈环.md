# Issue 4.3：策略迭代反馈环

**Milestone:** M4 - 销量回顾 Agent  
**优先级:** P1

## 描述

将本季度的**「避雷点」**（例如：某面料易皱导致高退货）存入 Agent 的**长期记忆（Memory）**，在**下一轮选品**时自动拦截或提醒类似款式。

## 验收标准

- [ ] 有结构化「避雷点」存储（款式/材质/工艺/供应商等 + 原因简述）
- [ ] 选品 Agent 在给出建议前可查询 Memory，对命中避雷点的款进行拦截或标注风险
- [ ] 避雷点可由人工或自动（如 4.2 归因结果）写入，并支持审核与过期归档

## 依赖与备注

- 依赖 M4 的归因输出（4.2）与 M2 选品流程；实现上需接入 Agent 的 Memory 或知识库能力。
