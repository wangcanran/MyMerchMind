# Issue 2.1：流行趋势映射逻辑

**Milestone:** M2 - 选品 Agent  
**优先级:** P2

## 描述

编写 **Prompt** 与逻辑，令 Agent 将社媒热点转化为**具体商品需求**。

**示例：**

- 社媒「美拉德」热度上升 → 建议增加**棕色系裙装**选品

## 验收标准

- [ ] 输入为趋势标签/关键词（可来自 Issue 1.2），输出为品类/款式/色系/材质等选品建议
- [ ] Prompt 中明确「从趋势到商品」的推理步骤，便于迭代与审核
- [ ] 建议可与现有商品标签（Issue 1.3）做匹配，标出已有款与缺口

## 依赖与备注

- 依赖 Issue 1.2（趋势数据）、1.3（商品标签）。可与 2.2 竞品分析结合，形成完整选品报告。
