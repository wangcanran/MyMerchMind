# Issue 2.3：首单定量策略建议

**Milestone:** M2 - 选品 Agent  
**优先级:** P2

## 描述

根据选品的**「风险等级」**自动给出**首批下单量（MOQ）**建议，防止首单盲目铺货。

## 验收标准

- [ ] 选品输出中每条建议带有「风险等级」或类似分类（如高/中/低）
- [ ] 针对不同风险等级给出首单量区间或公式（可结合历史爆款率、品类周转等）
- [ ] 说明可读、可被采购/业务直接参考或导入 Excel

## 依赖与备注

- 可与 M3 智能补货计算器（EOQ）区分：本 Issue 侧重「首单」，M3 侧重在销品补货量。
