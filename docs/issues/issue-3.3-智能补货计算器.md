# Issue 3.3：智能补货计算器

**Milestone:** M3 - 库存管理 Agent

## 验收标准

- [ ] 公式或逻辑可解释（如 EOQ 公式、季节性系数来源）
- [ ] 结果可生成 **Excel 采购单** 或结构化数据供确认（体现「Tool Use」能力，见避坑指南）
